# 📖 About InventraX ERP

**InventraX ERP** is a modern, enterprise-grade **Inventory Management and Point of Sale (POS) Platform** designed to streamline business operations through intelligent inventory control, procurement, sales management, financial reporting, and seamless online/offline synchronization.

The platform is built for organizations that require uninterrupted operations regardless of internet connectivity. Businesses can work **Online**, **Offline**, or in **Hybrid Mode**, with a secure synchronization engine ensuring data consistency between local and cloud databases.

InventraX ERP is suitable for:

- Retail Stores
- Supermarkets
- Pharmacies
- Warehouses
- Restaurants
- Hotels
- Manufacturing Companies
- Wholesale Businesses
- Multi-Branch Enterprises
- Distribution Companies

# 🌐 Online • Offline • Hybrid Mode

InventraX ERP provides three flexible operating modes.

| Mode | Description |
|-------|-------------|
| 🌍 Online | Connect directly to the cloud database |
| 💻 Offline | Operate entirely on a local MySQL database without internet |
| 🔄 Hybrid | Work locally while synchronizing securely with the cloud |

Administrators can switch between modes based on operational requirements.
